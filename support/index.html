자주 묻는 질문 Frequently asked questions

걸음 수가 0에서 움직이지 않아요 The step count stays at zero

동작 및 피트니스 권한이 없으면 걸음 수를 아예 셀 수 없습니다. 설정 → 앱 → 팽글 → 동작 및 피트니스를 켜주세요.
앱 안에서도 권한이 없으면 안내가 표시되고, 그 안내를 누르면 설정으로 바로 이동합니다. Without Motion & Fitness permission the app cannot count steps at all.
Turn it on in Settings → Apps → Pangle → Motion & Fitness. The app also shows a notice when the permission is missing; tapping it takes you straight to Settings.

권한이 켜져 있는데도 0이라면, 기기가 걸음 수 측정을 지원하지 않는 경우입니다.
이때는 앱이 “이 기기에서는 걸음 수를 측정할 수 없어요”라고 표시합니다. If the permission is on and it is still zero, the device cannot count steps.
In that case the app says so explicitly instead of showing a stuck number.

잠금화면이나 다이나믹 아일랜드에 달팽이가 안 나와요 The snail does not appear on the Lock Screen or in the Dynamic Island
  • 설정 → 앱 → 팽글 → 실시간 활동이 켜져 있어야 합니다.
    기본값은 켜짐입니다.     Settings → Apps → Pangle → Live Activities has to be on.
    It is on by default.
  • 걷기 시작해야 나타납니다.
    앱을 열어 걸음이 한 번 들어오면 잠금화면 카드가 생깁니다.     It appears once you start walking — open the app, and the Lock Screen card shows up as soon as steps arrive.
  • 다이나믹 아일랜드는 다이나믹 아일랜드가 있는 iPhone 모델에서만 표시됩니다.
    없는 기기에서는 잠금화면 카드로 같은 정보를 보여줍니다.     The Dynamic Island only exists on iPhone models that have it.
    On other iPhones the same information appears as the Lock Screen card.
앱을 닫으면 잠금화면 숫자가 멈춰요 The Lock Screen number freezes when I close the app

라이브 액티비티는 앱이 깨어 있을 때 갱신됩니다.
iOS가 앱을 정지시키면 화면의 숫자도 그 시점에 멈춥니다. 걸음 데이터 자체는 잃지 않습니다 — iPhone의 동작 코프로세서가 걸음을 계속 세고 있으므로, 앱을 다시 열면 정확한 하루 총합이 바로 표시됩니다. A Live Activity updates while the app is awake.
When iOS suspends the app, the number on screen stops where it was. No step data is lost — your iPhone’s motion coprocessor keeps counting, so reopening the app immediately shows the correct daily total.

닫아둔 동안에도 계속 갱신되게 하려면 껍데기 지도의 위치 기록을 켜고, 위치를 ‘항상 허용’으로 두세요(설정 → 앱 → 팽글 → 위치 → 항상). 위치가 들어올 때마다 앱이 잠깐 깨어나 걸음 수를 다시 읽습니다.
대신 배터리 사용량이 늘어납니다. To keep it updating while the app is closed, turn on route recording for the shell map and set location to “Always” (Settings → Apps → Pangle → Location → Always).
Each location update briefly wakes the app so it can re-read your steps.
It does use more battery.

껍데기 지도가 비어 있어요 The shell map is empty
  • 기록이 꺼져 있을 수 있습니다. 위치 기록은 기본 꺼짐이고, 껍데기 지도 화면에서 직접 켜야 시작됩니다. Recording may be off. It is off by default and starts only when you turn it on from the shell map screen.
  • 이동 범위가 너무 작으면 빈 껍데기를 보여줍니다.
    그날 움직인 범위가 60m가 안 되면 모양이 아니라 GPS 잡음이기 때문입니다.     If you barely moved, the shell stays empty: under about 60 m of range, what you would see is GPS noise rather than a shape.
  • 실내에서만 걸었다면 걸음은 쌓여도 위치가 바뀌지 않아 새길 길이 없습니다.
    러닝머신도 같습니다.     If you only walked indoors, steps accumulate but your position does not change, so there is no path to engrave.
    Treadmills are the same.
걸음 수와 껍데기 지도의 길이가 안 맞아요 The steps and the shell map disagree

정상입니다.
걸음 수는 만보계가 세고, 껍데기 지도는 위치가 바뀐 만큼만 그립니다.
실내 이동은 걸음에는 들어가지만 지도에는 남지 않습니다. That is expected.
Steps come from the pedometer; the shell map only draws where your position actually changed.
Indoor walking counts as steps but leaves no path.

또 두 지점의 기록이 10분 이상 떨어져 있으면 선을 잇지 않습니다.
아침에 집, 오후에 시내처럼 떨어진 구간을 이으면 실제로 걷지 않은 직선이 껍데기를 가로지르기 때문입니다. Also, two fixes more than ten minutes apart are not joined.
Connecting them — home in the morning, downtown in the afternoon — would draw a straight line across the shell that you never walked.

하루 목표를 바꾸고 싶어요 I want to change my daily goal

홈 화면의 하루 목표에서 고르거나, 직접 설정으로 원하는 숫자를 입력하면 됩니다.
목표를 바꾸면 트랙의 결승선이 멀어지거나 가까워집니다. Pick one under the daily goal on the home screen, or use Custom to type any number.
Changing the goal pushes the finish line away or pulls it closer.

앱 언어를 바꾸고 싶어요 I want to change the app’s language

앱 안에는 언어 스위치가 없습니다.
iOS의 앱별 언어 설정을 따르므로 설정 → 앱 → 팽글 → 언어에서 한국어와 English 중에 고르세요.
잠금화면 달팽이와 공유 이미지도 같은 언어를 씁니다. There is no in-app language switch.
The app follows the per-app language in iOS, so choose Korean or English in Settings → Apps → Pangle → Language. The Lock Screen snail and shared images use the same language.

PRO를 구매했는데 다른 기기에서 잠겨 있어요 I bought PRO but it is locked on another device

같은 Apple ID로 로그인한 뒤 설정 → 구매 복원을 누르세요.
PRO는 1회 결제 상품이라 계정에 남아 있고, 다시 결제하지 않아도 복원됩니다.
복원할 이력이 없다고 나오면 결제에 쓴 Apple ID가 맞는지 확인해 주세요. Sign in with the same Apple ID and tap Settings → Restore purchase. PRO is a one-time purchase kept on your account, so it restores without paying again.
If it reports nothing to restore, check that you are signed in with the Apple ID you paid with.

PRO를 환불하고 싶어요 I want a refund for PRO

인앱 구매의 결제와 환불은 Apple이 처리합니다.
개발자는 결제 내역에 접근할 수 없으므로 직접 환불해 드릴 수 없습니다. reportaproblem.apple.com에서 요청하세요. Apple handles payment and refunds for in-app purchases.
The developer cannot access purchase records and therefore cannot issue a refund.
Request one at reportaproblem.apple.com.

    당장 지우고 싶다면 위치 권한을 끄거나 앱을 삭제하면 됩니다.     Route recording: it disappears on its own after midnight.

자세한 내용은 개인정보 처리방침에 정리해 두었습니다. The privacy policy covers this in detail.

iPad, Apple Watch, Android에서도 쓸 수 있나요? Is there an iPad, Apple Watch or Android version?

현재는 iPhone 전용입니다(iOS 17.0 이상). Apple Watch 앱과 Android 버전은 없습니다. Right now it is iPhone only (iOS 17.0 or later).
There is no Apple Watch app and no Android version.

기기를 바꾸면 기록이 옮겨지나요? Does my history move to a new device?

걸음 기록과 껍데기 지도는 기기 안에만 저장되므로 기기 사이에 동기화되지 않습니다.
계정이 없기 때문입니다.
기기를 바꾼 뒤 옮겨지는 것은 PRO 구매뿐이고, 그것도 설정 → 구매 복원으로 직접 복원합니다. Step history and shell maps are stored only on the device and do not sync between devices — there is no account to sync them to.
The one thing that carries over is the PRO purchase, restored yourself with Settings → Restore purchase.
